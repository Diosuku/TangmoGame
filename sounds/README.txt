โฟลเดอร์เสียงเอฟเฟกต์ (SFX)
===========================
วางไฟล์เสียงของคุณในโฟลเดอร์นี้ (โฟลเดอร์ "sounds" ต้องอยู่ข้างไฟล์ TangmoGame.jar)
แล้วเปิดเกมใหม่ ไม่ต้องคอมไพล์อะไรเพิ่ม

ชื่อไฟล์ที่เกมจะหา        เล่นเมื่อ
------------------------  ------------------------------------------------------
drop.wav                  ปล่อยผลไม้ลงกล่อง
merge.wav                 รวมผลไม้ (เกมจะเลื่อนระดับเสียงให้สูงขึ้นตามขนาดผลไม้ใหม่ให้เอง)
shoot.wav                 ยิงเมล็ดใส่บอส (ยิงถี่ ควรเป็นเสียงสั้น ๆ ราว 0.05 - 0.15 วินาที)
win.wav                   ชนะบอส หรือรวมได้แตงโม
lose.wav                  แพ้ (ผลไม้ล้นกล่อง หรือหัวใจหมด)

ตัวเลือกเสริม: ถ้าอยากกำหนดเสียงรวมผลไม้แยกทีละชนิดเอง ให้ใช้ชื่อ
  merge_strawberry.wav  merge_grape.wav  merge_dekopon.wav
  merge_persimmon.wav   merge_watermelon.wav
(ชื่อชนิดคือผลไม้ที่ "ได้ใหม่" จากการรวม ไฟล์เหล่านี้จะมาก่อน merge.wav)

รูปแบบไฟล์ที่รองรับ
  - .wav (แนะนำ)  .aiff / .aif  .au
  - PCM 8 / 16 / 24 / 32 บิต, โมโนหรือสเตอริโอ, อัตราสุ่มตัวอย่างอะไรก็ได้
  - ไม่รองรับ .mp3 และ .ogg โดยตรง ให้แปลงเป็น .wav ก่อน (เช่นด้วย Audacity หรือ ffmpeg:
      ffmpeg -i เสียง.mp3 drop.wav )
  - ไฟล์ต้องไม่ใหญ่เกิน 8 MB (เสียงเอฟเฟกต์ควรสั้นอยู่แล้ว)

ถ้าไม่มีไฟล์ใดไฟล์หนึ่ง หรือไฟล์เสียหาย/อ่านไม่ได้ เกมจะใช้เสียงในตัวแทนเฉพาะเสียงนั้น
(และแจ้งเตือนทางหน้าต่าง console หากเปิดด้วย java -jar)

ไฟล์ตัวอย่างที่ให้มาเป็นเสียงเริ่มต้นของเกม สามารถเขียนทับได้เลย
